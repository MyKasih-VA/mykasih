import { createClient } from '@supabase/supabase-js'

2. **Constants:**
```typescript
const IC_PATTERN = /\d{6}-\d{2}-\d{4}/  // dashed unmasked
const IC_PLAIN_PATTERN = /\d{12}/  // plain 12-digit
const MASKED_PATTERN = /\d{6}-\*\*-\*\*\*\*/  // already masked -- exclude
```

3. **COLUMNS_TO_SCAN array** -- per D-01, scan every text and jsonb column across all tables (D-01 specifies 7 tables; settings and ticket_notes added under Claude's Discretion for broader coverage):
```typescript
const COLUMNS_TO_SCAN: Array<{ table: string; columns: string[]; type: 'text' | 'jsonb' }> = [
  { table: 'calls', columns: ['caller_name', 'wa_number', 'location', 'postcode', 'elevenlabs_conversation_id'], type: 'text' },
  { table: 'transcripts', columns: ['message'], type: 'text' },
  { table: 'tickets', columns: ['description', 'masked_ic', 'reference_no', 'assigned_to'], type: 'text' },
  { table: 'kb_entries', columns: ['category', 'question_bm', 'question_en', 'answer_bm', 'answer_en', 'updated_by'], type: 'text' },
  { table: 'users', columns: ['email', 'name'], type: 'text' },
  { table: 'merchants', columns: ['chain', 'outlet_name', 'state', 'city', 'postcode', 'address'], type: 'text' },
  { table: 'sessions', columns: ['collected_data'], type: 'jsonb' },
  { table: 'settings', columns: ['value'], type: 'text' },
  { table: 'ticket_notes', columns: ['content'], type: 'text' },
]
```

4. **`scanTable` function:** For each table/column combination:
   - SELECT id, column FROM table
   - For text columns: test each value against IC_PATTERN and IC_PLAIN_PATTERN
   - Exclude values matching MASKED_PATTERN (already masked)
   - For jsonb columns: cast to string first, then test
   - Return array of `{ table, column, rowId, value, matched }` findings

5. **`remediateRow` function (per D-03):** For each finding:
   - For text columns: UPDATE table SET column = regexp_replace(column, '(\d{6})-?\d{2}-?\d{4}', '\1-**-****', 'g') WHERE id = rowId
   - Use the Supabase client `.rpc()` or raw SQL via `.from().update()`
   - Log: `[REMEDIATED] table.column row=rowId before=<value> after=<masked>`

6. **`scanCodebase` function (per D-02):** Use Node.js `fs` and `path` to recursively read `.ts`, `.tsx`, `.js`, `.json`, `.env*`, `.md` files in the mykasih-crm directory. Search for patterns matching `\d{6}-?\d{2}-?\d{4}` that are NOT already masked. Exclude `node_modules/`, `.next/`, `scripts/pdpa-audit.ts` itself. Report file path + line number + matched value.

7. **`generateReport` function (per D-04):** Produce a markdown string with:
   - Header: "# PDPA Compliance Audit Report"
   - Metadata: date, auditor (automated), scope
   - Section per table: table name, columns checked, findings count, pass/fail
   - Remediation log: every row changed with before/after
   - Codebase scan results
   - Final sign-off section with overall PASS/FAIL

8. **`main` function:** Run scanTable for all entries, remediate findings, scan codebase, generate report, write to stdout AND to `PDPA-AUDIT.md`.

Run command: `cd mykasih-crm && SUPABASE_URL=$NEXT_PUBLIC_SUPABASE_URL SUPABASE_SERVICE_ROLE_KEY=$SUPABASE_SERVICE_ROLE_KEY npx tsx scripts/pdpa-audit.ts`

Note: The script should exit cleanly even if some tables don't exist yet (catch errors per table, log as "table not found -- skipped").
