**Step 3 — Create `/api/analytics/charts/route.ts`:**
Create a new GET route at `mykasih-crm/app/api/analytics/charts/route.ts`. Follow the pattern from `/api/analytics/summary/route.ts`:
- Import `createClient` from `@/lib/supabase/server`
- Auth check: `await supabase.auth.getUser()` — return 401 if no user
- Accept query params: `period` (today | thisWeek | thisMonth | last3Months), `from` (ISO date), `to` (ISO date)
- Compute date range from period param: today = start of today; thisWeek = start of current week (Monday); thisMonth = start of current month; last3Months = 90 days ago; if `from` and `to` provided, use those directly
- Filter all queries with `.eq('is_test', false).gte('timestamp', fromDate).lte('timestamp', toDate)`
- Return JSON with this shape:

```typescript
{
  stats: {
    totalInteractions: number,
    avgCsat: number | null,
    resolutionRate: number,
    peakHour: string // e.g. "14:00"
  },
  volumeByDay: Array<{ date: string, voice: number, chat: number }>,
  csatByDay: Array<{ date: string, avg: number }>,
  languageDistribution: Array<{ name: string, value: number }>, // BM, EN, Mixed
  heatmap: Array<{ day: number, hour: number, count: number }>, // day 0=Mon..6=Sun, hour 0-23
  categoryBreakdown: Array<{ category: string, voice: number, chat: number, total: number, percentage: number }>
}
```

For stats:
- `totalInteractions`: count of calls in range
- `avgCsat`: average of `csat_rating` where not null, rounded to 1 decimal. Return null if no ratings.
- `resolutionRate`: `(resolved count / total count) * 100`, rounded to integer
- `peakHour`: find the hour with most interactions, format as "HH:00"

For volumeByDay: group calls by date (YYYY-MM-DD), count voice and chat separately.

For csatByDay: group calls with non-null csat_rating by date, compute daily average.

For languageDistribution: count calls grouped by language field (bm, en, mixed).

For heatmap: extract day-of-week (0=Mon..6=Sun) and hour (0-23) from each call timestamp, count per (day, hour) cell.

For categoryBreakdown: group by category, count voice and chat separately, compute total and percentage of all.
