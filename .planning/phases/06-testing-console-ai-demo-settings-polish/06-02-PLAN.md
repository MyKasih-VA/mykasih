## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client -> /api/chatbot/message | Chatbot simulator sends user input to the API |
| client -> ElevenLabs WebRTC | Voice session connects to external service |
| client -> /api/calls | Fallback POST to tag test calls with is_test=true |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-03 | Tampering | ChatbotSimTab -> /api/chatbot/message | mitigate | Simulator sends `isTest: true` in request body. The chatbot route already validates n8n secret conditionally (skips if env var not set). Simulator calls are admin-only (behind dashboard auth proxy). No additional auth needed for internal route. |
| T-06-04 | Tampering | VoiceAgentTab is_test flag | mitigate | Pass is_test=true via SDK metadata (dynamic_variables or equivalent). Additionally, implement fallback POST to /api/calls in onDisconnect to unconditionally guarantee is_test=true reaches Supabase. Both paths are admin-only (behind dashboard auth proxy). |
| T-06-05 | Information Disclosure | ElevenLabs WebRTC session | accept | Voice data flows through ElevenLabs infrastructure. This is inherent to the integration. No beneficiary PII is transmitted — admin is testing with synthetic data. |
| T-06-06 | Denial of Service | Rapid chatbot simulator sends | accept | Rate limiting not required for admin-only testing tool. Simulator is behind auth. |
</threat_model>
