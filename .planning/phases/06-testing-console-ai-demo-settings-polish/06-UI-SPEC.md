## Spacing Scale

Declared values (multiples of 4 only):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline element padding, dot indicator margins |
| sm | 8px | Compact element spacing, button icon gap, tab padding |
| md | 16px | Default element spacing, card inner padding, form field gap |
| lg | 24px | Section padding, card-to-card gap, chat bubble gap |
| xl | 32px | Layout column gaps, major content block spacing |
| 2xl | 48px | Page-level vertical rhythm between sections |
| 3xl | 64px | Demo page vertical padding above/below center content |

**Exceptions:**
- Chat bubble area fixed height: `h-[420px]` (420px = 105 * 4px — aligns to 4px grid). Source: CONTEXT.md D-08.
- Anam AI embed minimum height: `min-height: 480px` (480px = 120 * 4px — aligns to 4px grid). Source: RESEARCH.md Pattern 2.
- Mic button touch target: 64px × 64px minimum (aligns to 4px grid, meets 44px WCAG minimum with additional padding).
- Status badge dot: 8px × 8px (sm token).

## Typography

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 14px | Regular (400) | 1.5 | Chat bubble text, settings field values, transcript lines, table cell text |
| Label | 12px | Regular (400) | 1.4 | Status badge text, intent badge text, caption beneath mic button, tab labels, webhook URL labels |
| Heading | 20px | SemiBold (600) | 1.2 | Page title ("Testing Console", "Settings"), card section headers ("Agent Hours", "Webhook URLs") |
| Display | 28px | SemiBold (600) | 1.1 | Demo page "AI Helpline Demo" title only |

**Weight scale used: exactly 2 weights — Regular (400) and SemiBold (600).** Source: CLAUDE.md typography section.

**Font family rules:**
- All UI text: Inter via `var(--font-sans)`. Source: globals.css.
- Webhook URLs in Settings read-only inputs: JetBrains Mono via `var(--font-mono)`. Rationale: URLs are technical strings; monospace improves readability.
- No other monospace usage in this phase.

## Interaction Contracts

### Voice Agent Tab

| Interaction | Trigger | Behavior |
|------------|---------|---------|
| Start session | Click "Start Session" button | Call `startSession()` (synchronous, no await per SDK v1.1.0) — button state → Connecting → Active on `onConnect` callback |
| Live transcript | `onMessage` callback fires | Append new message to transcript panel; auto-scroll to bottom |
| End session | Click "End Session" button | Call `endSession()` — status → Ended; mic button returns to idle state |
| Error | `onError` callback fires | Show toast.error with `testing.voice.error` copy; status → Ready |

### Chatbot Simulator Tab

| Interaction | Trigger | Behavior |
|------------|---------|---------|
| Send message | Enter key or Send button click | Append user bubble; show loading dots; POST to `/api/chatbot/message`; append bot bubble + intent badge on response |
| First contact | API returns `{ status: 'first_contact' }` | Render synthetic welcome bubble (static copy, no intent badge) |
| Clear | Clear Conversation button click | Reset `messages` state to `[]`; reset session state |
| Auto-scroll | New message added to state | Scroll bubble area `scrollTop = scrollHeight` |

### Settings Page

| Interaction | Trigger | Behavior |
|------------|---------|---------|
| Load settings | Page mount | `GET /api/settings` → populate form fields; show skeleton while loading |
| Save | Save Changes button click | Validate fields (HH:MM format, email format, integer); `PATCH /api/settings`; `toast.success(t('settings.saveSuccess'))` on success; `toast.error(t('settings.saveError'))` on failure |
| Copy webhook URL | Copy button click | `navigator.clipboard.writeText(url)` then `toast.success(t('settings.copyUrl'))` |

### Language Toggle (TEST-06 Polish)

| Rule | Behavior |
|------|---------|
| Scope | Every visible string on every dashboard page uses `t('key', language)` |
| Exceptions | Dynamic DB data (names, WA numbers, timestamps), vendor embed content (Anam AI, ElevenLabs widgets) |
| Demo page | English only — no language toggle, no `t()` calls needed |
| Implementation | Replace all `language === 'en' ? '...' : '...'` inline ternaries with `t()` calls |
