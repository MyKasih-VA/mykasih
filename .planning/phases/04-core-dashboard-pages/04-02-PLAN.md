**Data fetching:** `useCallback` + `useEffect` pattern:
- Build URLSearchParams: always set `channel=voice`, `page={page}`, `limit=25`
- Map filter fields: if `filters.search` -> set `search` param. If `filters.category` -> set `category`. If `filters.outcome` -> set `outcome`. If `filters.language` -> set `language`.
- Date mapping: convert `datePreset` to `from`/`to` params:
  - `'today'`: from = today's date (YYYY-MM-DD), to = today's date
  - `'week'`: from = Monday of current week, to = today
  - `'month'`: from = 1st of current month, to = today
  - `'custom'`: use filters.dateFrom and filters.dateTo directly
  - `''` (all time): no date params
- Reset page to 1 when filters change
- Fetch from `/api/calls?${params}`, check `.ok`, parse JSON, set data + pagination. On error set `error=true`.

**Export handler:**
```typescript
async function handleExport() {
  setExporting(true)
  try {
    const params = new URLSearchParams()
    if (filters.dateFrom) params.set('from', filters.dateFrom)
    if (filters.dateTo) params.set('to', filters.dateTo)
    const res = await fetch(`/api/export/calls?${params}`)
    if (!res.ok) throw new Error()
    const blob = await res.blob()
    const url = URL.createObjectURL(blob)
    const a = document.createElement('a')
    a.href = url
    a.download = `mykasih-calls-${new Date().toISOString().slice(0, 10)}.xlsx`
    a.click()
    URL.revokeObjectURL(url)
  } catch { /* silently fail — export is best effort */ }
  setExporting(false)
}
```
